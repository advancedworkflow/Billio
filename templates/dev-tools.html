🛠️ Outils de Développement

Guide complet pour utiliser les outils de développement de Billio

🎯 Introduction

Billio inclut des outils de développement puissants pour vous permettre de modifier et visualiser les changements en temps réel. Ces outils sont parfaits pour le développement, les tests et l'optimisation.

Mode Sécurisé

Les outils de développement ne sont disponibles qu'en mode démo et ne modifient pas les données réelles.

🔧 Barre d'Outils de Développement

🛠️ Mode Édition - Billio
Page: /invoices/create/ Quitter

🎯 Grille

Affiche une grille de référence pour aligner les éléments.

📦 Contours

Met en évidence tous les éléments avec des bordures colorées.

ℹ️ Info

Affiche les informations CSS des éléments survolés.

✏️ Édition en Direct

Les éléments marqués avec un indicateur d'édition peuvent être modifiés en temps réel.

⚠️

Limitations

L'édition en direct est actuellement en mode démonstration. Les changements ne sont pas sauvegardés de manière permanente.

Éléments éditables

  • Titres et sous-titres
  • Textes descriptifs
  • Contenus statiques

Comment éditer

  1. Survolez un élément avec un contour bleu
  2. Cliquez sur le bouton ✏️ qui apparaît
  3. Modifiez le contenu dans la fenêtre modale
  4. Cliquez sur "Sauvegarder"

⌨️ Raccourcis Clavier

Navigation

Basculer grille: G
Basculer contours: O
Info éléments: I

Édition

Annuler: Ctrl+Z
Sauvegarder: Ctrl+S

🔌 Points d'API pour les Outils

Sauvegarde des modifications

POST /api/dev-tools/save-changes/

Sauvegarde les modifications d'éléments éditables.

Export des styles

GET /api/dev-tools/export-css/

Exporte les styles personnalisés au format CSS.

Reset des modifications

POST /api/dev-tools/reset/

Remet à zéro toutes les modifications temporaires.
